# 🎯 Encapsulation Practice Set (Real Growth)

## 🔴 1. Student System (Basic but important)

**Class: `Student`**

### Rules:

* `name` → private
* `marks` → private

### Conditions:

* marks 0–100 ke beech hi set ho
* agar invalid ho → "Invalid marks" print
* ek method ho:

  * `isPass()` → return true/false (>= 40 pass)

👉 Output main me check kar

---

## 🔴 2. ATM Machine (Real-world feel)

**Class: `ATM`**

### Rules:

* `balance` → private
* initial balance constructor se set hoga

### Methods:

* `deposit(amount)` → amount > 0
* `withdraw(amount)` →

  * amount valid ho
  * balance sufficient ho
* `checkBalance()` → return kare

👉 Twist:

* balance kabhi negative nahi hona chahiye

---

## 🔴 3. Employee Salary System

**Class: `Employee`**

### Variables:

* `salary` → private

### Rules:

* salary kabhi negative nahi
* method:

  * `setSalary()` with validation
  * `getSalary()`
  * `increaseSalary(percent)`
    👉 percent negative nahi ho sakta

---

## 🔴 4. Mobile Battery System (thoda logic)

**Class: `Mobile`**

### Variables:

* `battery` (0–100)

### Rules:

* charge(amount) → battery 100 se upar nahi jayega
* use(amount) → battery 0 se niche nahi jayega

👉 Hint:

```java id="9w9z8q"
battery = Math.min(100, battery + amount);
```
